# 정답 확보 및 팀 배포 계획

사용자 2026-10-09 지시에 따라 기존 영상/64프레임/12문제를 재사용한다.
원본 모델링/후보/데이터 폴더와 기존 실행 결과는 수정하지 않는다.

1. MAIN이 6영상의 시각적 시간 흐름을 직접 확인한다. 의학·법적 권한·의도는 추정하지 않는다.
2. 각 단독 문제의 0,21,42,63번 입력 위치 총24프레임에 RT-DETR-L 독립 COCO 탐지로
   박스 초안을 만든다. 평가 대상 YOLO26s 결과는 정답 작성에 사용하지 않는다.
3. MAIN이 실제 이미지와 번호가 표시된 박스를 대조하여 수락/수정/추가/제외한다.
   모호하거나 전체 객체를 확인하기 어려운 프레임은 complete=false로 미평가한다.
   직접 확인한 클래스/박스만 정답에 넣고 미측정 프레임을 빈 정답으로 간주하지 않는다.
4. 라우팅 기준: 시각적 이상행동이 있거나, 가림/권한/행동 여부가 모호하여 추가 시각 검토가
   필요한 경우 invoke_vlm=true. 명시적으로 정상임이 확인된 경우만 false.
   검토 대상 영상의 이름으로 호출 정답을 결정하지 않는다. 영상별 근거와 판단을 보존한다.
5. 정답은 AI 모델 초안 + MAIN의 AI 시각 검수이다. 독립 전문가/사람 이중 검수로 표시하지 않는다.
   demo AI-reviewed reference로 동결하며 production gold-standard 성능으로 일반화하지 않는다.
6. 팀 배포: 공개 input_frames/prompt/manifests + 빈 submission_template.csv + score.py.
   비공개 정답은 별도 evaluator 영역이다. 자기 결과를 CSV/연결 JSON에 채운 후 자동 채점한다.
   기존 단계별 검출/라우팅/사건/출력 유효성 평가 코드를 재사용한다.
7. 정답과 라우팅의 구조/시각 검토가 통과한 후에만 기존 파이프라인 실패를 분석/수정한다.
   기존 fixed prompt의 정책 지시 차이 수정은 별도 명시 버전으로 분리한다.

완료 조건: 실제 시각 검수 기록/박스 출처, 동결 정답 해시, 최소한의 객체 평가 가능 프레임,
6영상 사건/라우팅 정답 또는 명시적 불확실 판정, 12행 결과 템플릿, 정답/오답/누락/타인입력
자기검증을 통과한 자동 채점기, 기존 결과의 재채점(추론 재사용 표시), 새 버전 실행 가이드.

역할: model_engineer는 annotation_detector.py와 테스트, evaluation_engineer는 별도
채점 모듈과 테스트, reviewer는 읽기 전용 검토. 공통/배포/정답 확정은 MAIN. 에이전트 순차 실행.
