# 실제 결과와 남은 검수

**12문제 전체에서 YOLO → Clef → DeepSeek를 실제 실행했습니다. 사건 정확도는 아직 평가 불가입니다.**
검수된 객체 박스·라우팅 정답·사건 정답이 없습니다. 실행 완료, 출력 형식, 사건 정답 여부를 구분합니다.

최종 표는 [results_readable.csv](results/full_pipeline_v2/results_readable.csv)입니다.
문제당 한 행으로 12행이며 JSON 셀 최대 8,477자입니다. 긴 YOLO 박스/추적 및 이미지별
메타데이터는 normalized 파일 링크로 확인합니다. 같은 수치의 원본 `results.csv`와
각 `Pxxx/result.json`도 유지했습니다. 두 CSV를 합쳐 24문제로 계산하지 마세요.

## 실제 실행

2026-10-08 UTC / 2026-10-09 한국 시각. 고유 영상 6개, 영상 등장 28회, 12문제 × 64장.
각 문제 1회, 매번 새로운 YOLO 프로세스이므로 로딩 포함입니다.

- YOLO26s + ByteTrack: CPU, imgsz=960, conf=0.1, pose 미사용.
  Ultralytics 8.4.174, PyTorch 2.9.1+cpu.
- Clef: `@cf/cloudflare/clef`, 실제 12요청, 64프레임에서 만든 CV 특징 JSON, 이미지 0장.
- VLM: 실제 요청·응답 `deepseek-flash`, 12요청, 동일 64이미지, 원본 해상도의 JPEG quality=80.
  crop·추가 프레임·CV 특징 미전달. 제공자 내부 축소/VRAM은 미측정입니다.
  공식 문서의 Flash 버전은 DeepSeek-V4.1-Flash지만 실제 응답은 모델 별칭만 확인했습니다.

VLM 원본은 수정하지 않았습니다. `model_error`는 출력 계약 위반이며 원인이 전부 모델
능력 부족이라는 뜻은 아닙니다. 프롬프트는 미측정 축을 null로 두고 불확실할 때 검토하라고
설명하지만, 평가기의 **축 하나라도 null 또는 confidence<0.90이면 검토 필요** 조건을
그대로 명시하지 않습니다. 이 지시 차이는 벤치마크 개선 항목이며 기여 가능성이 있습니다.
이번 실행 중 프롬프트·합격 기준은 변경하지 않았습니다.

`metrics.vlm.output_format_valid`는 schema 검사입니다. 어댑터 메타데이터 `format_valid`는
추가 검토 정책까지 포함해 값이 다를 수 있습니다. 어느 값도 사건 정답을 뜻하지 않습니다.

## 원인 구분과 개선 순서

1. **정답 확보**: 객체 클래스/xyxy 박스·완전 주석 여부, 사건 라벨, 영상별 호출 정책을
   검수해 ground_truth에 기록하세요. 구역·권한·시간 정책과 정상 영상도 필요합니다.
2. **지시와 계약 일치**: null 축·낮은 confidence의 검토 조건을 명시하는 새 프롬프트 버전을
   별도로 비교하세요. 이번 결과나 기준을 소급 수정하지 않습니다.
3. **속도**: CPU YOLO 상주 프로세스/모델 재사용 또는 GPU부터 비교합니다. JPEG 변환
   캐시도 고정 입력 해시를 유지한 별도 실험으로 비교합니다. 현재 미실행입니다.
4. **Clef 역할**: 현재 CV 구역·행동 판정·위험축이 미확정이라 28/28 VLM 호출입니다.
   호출 절감은 0, 지연은 추가됐습니다. 정상 대조군과 운영 정책 확보 후 라우팅 이득을 평가합니다.
5. **시각 실패 분석**: SRC02의 구성별 변화와 SRC04/SRC05의 참고 설명 차이를 실제
   근거에서 검수하세요. 작은 객체·시점·샘플링·프롬프트 원인은 아직 가설입니다.
   dense 입력/crop/추가 특징 실험은 공통 결과와 분리합니다.

수정 완료한 벤치마크 오류: 실행 전 정답 schema JSON 문법, 잘못된 YOLO 응답 원문 덮어쓰기,
단일 관측 트랙의 정상 null 간격 거부. 마지막 오류로 v1을 중단하고 v2를 전체 재실행했습니다.
결과 읽기 도구의 CSV 128KiB 제한도 수정했습니다. 추론·평가 기준은 변경하지 않았습니다.
v2의 모델 계약 실패와 정답 부족을 분리했으며 확정되지 않은 사건 오답을 만들어 집계하지 않았습니다.

GPU 생성·학습·dense/crop 실험·정상 영상 수집은 미실행입니다. 6개 후보의 소규모 데모이며
전체 CCTV 환경으로 일반화하지 않습니다.
