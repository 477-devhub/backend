# Submissions

Use your pipeline directory and submit `run_ITEM_01.json` through `run_ITEM_07.json`.
Each file must satisfy the common result schema and public validator.
Set `human_grading` to null. Include source code, dependencies and actual runtime configuration.
The assignment directories are intentionally empty; no predictions or measurements are supplied.
Submission output files are generated later and are excluded from the immutable package file lock.
