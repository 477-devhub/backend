# 사용자가 추가로 확인·준비할 항목

코드의 입력 차단·시각 표현·실패 집계를 수정하고 실제 API 실험을 완료했다.
별도 pose-off 실험에서 CV 시간 중앙값은34.5% 감소했다. 자세 정보가 필요한
사건의 정확도가 유지되는지는 아직 측정할 수 없다.
다음 항목은 실제 데이터와 운영 정책이 필요하므로 코드에서 추정해 채울 수 없다.
이번 결과는 소규모 데모이며 실제 CCTV 전체의 사건 탐지 성능을 증명하지 않는다.

## 정답 JSON 전달 때 확인

- 원본 영상 파일명과 중립 ITEM/clip ID의 매핑을 평가 쪽에만 전달한다.
- `frame_id`가 0부터인지 1부터인지, 실제 fps, 카메라별 시간 오프셋을 확인한다.
- caption/answer/evidence/bbox는 평가에만 쓴다. 추론 입력이나 라우팅 기준에 넣지 않는다.
- 정상 영상도 포함하고, 가림·원거리 인물·조명 변화 등 어려운 경우를 구분한다.
- 원래 예시처럼 사건 frame 범위와 evidence frame hint가 다르면 annotation
  작성자에게 기준을 확인한다. 프레임을 임의로 교정해 정답으로 사용하지 않는다.
- 구역/시간 기준은 GT label에서 역산하지 않고 실제 운영 정책에서 전달한다.

## 이후 코드 개선 우선순위

1. 정답·운영 정책 확보 후 CV 구역/시간 규칙 및 행동 단서 평가. 촘촘한 영상 추적은
   별도 frame budget 실험으로 분리하고 64프레임 결과와 혼합하지 않는다.
2. 자세 분석을 필요한 경우에만 실행하는 정책 검증. pose-off 속도 결과만으로
   조건부 pose의 민감도를 보장하지 않는다. 넘어짐 누락을 먼저 확인한다.
3. CV worker 모델을 유지하는 warm 실행과 GPU 프로파일 비교. 현재 매회 import/load를
   수행한다. 캐싱의 예상 이득을 실제 측정치로 부르지 않는다.
4. Clef의 라우팅 이득 검증. 현재 CV는 검증된 정상 event assessment를 만들지
   못하므로 모든 입력을 VLM+사람 검토로 보낸다. 정상 증명 없이는 자동 억제하지 않는다.
   원본 사건 누락까지 분모에 포함한 평가가 가능해진 뒤 라우팅 정책을 확정한다.
5. 서비스 통합은 별도 작업. 현재 실제 API 개선은 benchmark CLI 경로이며,
   기존 ASGI의 Clef/VLM 슬롯을 실제 모델로 연결하는 운영 통합은 자동으로 완료되지 않는다.
   공통 ModelInput/검토·위험도 계약을 검증하고 팀원 handoff 뒤 MAIN이 통합한다.

새 GPU·추가 유료 반복 실험·학습은 이번 작업에 포함하지 않았다. 누적 $5 ledger를
삭제하지 않는다. 다음 유료 실험은 잔여 안전예약과 별도 승인 예산을 먼저 확인한다.

## Clef 계정 한도와 추가 실험

Cloudflare 공식 정책의 무료 일일 할당량은10,000Neurons이고 매일00:00UTC
(한국시간09:00)에 갱신된다. 계정의 다른 작업도 사용량에 영향을 줄 수 있으므로
대시보드에서 확인한다. Workers Paid 전환은 사용자의 계정·요금 결정이며 실행하지 않았다.
[공식 Workers AI 요금·갱신 정책](https://developers.cloudflare.com/workers-ai/platform/pricing/).

무료 할당량이 갱신되어도 이번 작업의 누적$5 안전예약은$4.99158528이라 추가
실험 여유가 없다. 계정 한도와 실험 예산은 별도다. 신규 예산을 명시하기 전
추가 유료 호출을 하지 않으며 기존 ledger를 초기화하지 않는다.

외부 자료를 준비하면 우선 정답 기반 실패 분류와 pose-on/off 비교부터 진행한다.
이후 warm CV worker/GPU 실행을 측정하고, 정상 여부를 검증할 수 있을 때
Clef 라우팅으로 줄인 VLM 호출 수와 사건 누락을 함께 평가한다.
