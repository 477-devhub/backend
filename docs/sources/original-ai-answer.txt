# 2. 왜 schema를 먼저 동결하라고 했냐

네 프로젝트에서는 이 부분이 제일 중요해.

예를 들어 Local CV가:

```json
{
  "fall": 0.84,
  "track": []
}
```

를 반환하고,

Clef가:

```json
{
  "event": "collapse",
  "severity": 4
}
```

를 반환하고,

VLM이:

```json
{
  "answer": "A person appears to have collapsed."
}
```

를 반환하면 비교가 불가능해져.

그래서 전부 최종적으로 이것으로 변환하게 해놨어.

```python
ModelAssessment
```

대략:

```json
{
  "event_type": "collapse",

  "event_confidence": 0.92,

  "risk_axes": {
    "severity": 0.90,
    "imminence": 0.95,
    "exposure": 0.80,
    "persistence": 0.85
  },

  "needs_human_review": false,

  "uncertainty_reason": null,

  "evidence_refs": [
    "frame_01",
    "frame_04"
  ],

  "metadata": {
    "adapter": "clef_direct",
    "model": "clef",
    "latency_ms": 210,
    "estimated_cost_usd": 0.0001
  }
}
```

그럼 evaluation 코드는 모델 종류를 몰라도 돼.

# 3. Local CV도 반드시 같은 Adapter로 만들어

이게 꽤 중요해.

```python
class ModelAdapter:

    async def evaluate(
        self,
        model_input: ModelInput
    ) -> ModelAssessment:
        ...
```

그리고:

```text
LocalCVAdapter
ClefDirectAdapter
GeneralVLMAdapter
```

가 전부 이걸 구현하도록 해야 해.

그러면 나중에:

```bash
python -m app.eval.runner \
  --adapter local_cv \
  --input fixtures/model_input.json
```

```bash
python -m app.eval.runner \
  --adapter clef_direct \
  --input fixtures/model_input.json
```

```bash
python -m app.eval.runner \
  --adapter general_vlm \
  --input fixtures/model_input.json
```

처럼 똑같이 실행할 수 있어.

현재 Kit에는 실제 API 대신 **mock adapter**를 넣어놨기 때문에 interface부터 테스트 가능하게 해놨어.

# 4. 그 다음 Codex에게 모델 구현을 맡기는 방법

스키마가 확정됐으면 이제 `model_engineer`를 사용한다.

예를 들어 Local CV를 먼저 만든다면:

```text
Use model_engineer.

Implement the Local CV baseline only.

Ownership:
- app/models/adapters/**
- app/eval/**
- related model tests

Do not modify:
- app/schemas/**
- app/models/base.py
- app/api/**
- app/services/**

Requirements:

1. Input must be ModelInput.
2. Output must be ModelAssessment.
3. No test or ground-truth labels may be passed into inference.
4. Start with a minimal CCTV baseline suitable for:
   - collapse
   - conflict
   - intrusion
5. Extract measurable temporal state where possible:
   - person tracking
   - motion
   - standing-to-ground transition
   - stationary duration
   - zone crossing
6. Record inference latency.
7. Keep model-specific dependencies isolated.

Use fixtures for tests first.

Run tests before reporting completion.
```

여기서 중요한 건 **소유 파일을 명시하는 것**이야.

# 5. Clef는 별도 Agent 작업으로 주면 된다

Local CV가 완성된 이후:

```text
Use model_engineer.

Implement ClefDirectAdapter.

Do not change the common schemas.

Input:
- temporal_state from Local CV
- selected evidence frames

Clef is used as the multimodal decision model,
not as a free-form text generator.

Map Clef decisions into ModelAssessment.

At minimum evaluate:
- event_type
- severity
- imminence
- exposure
- persistence
- needs_human_review

Store:
- latency
- API/model identifier
- usage/cost data if the API exposes it
- errors/timeouts

On Clef failure:
return or raise through the common safe failure path.
Do not silently fabricate a prediction.

Add adapter contract tests.
```

그리고 VLM도 똑같이:

```text
Use model_engineer.

Implement GeneralVLMAdapter.

It must consume the same ModelInput used by ClefDirectAdapter
and return exactly the same ModelAssessment schema.

Use schema-constrained structured output.

Do not let free-form text become application state.

The evaluation must therefore be able to compare:

local_cv
vs
clef_direct
vs
general_vlm

on the exact same samples.
```

이렇게 시키면 된다.

와

backend_engineer

를 병렬로 돌려도 된다.

- app/repositories/**
- app/main.py

# 10. 여기서 절대로 하면 안 되는 것

예를 들어:

```text
train/
  collapse/
  fight/
```

경로를 모델 입력으로 그대로 넘기면 안 돼.

왜냐하면:

```text
collapse/sample123.mp4
```

라는 path 자체가 정답을 알려주기 때문이야.

이게 전형적인 **label leakage**다.

그래서 모델에는:

```text
video bytes
temporal features
camera context
```

만 주고,

Evaluator만:

```text
ground truth
```

를 알아야 한다.
